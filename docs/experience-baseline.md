# 体验场景最终基线

VLESS RAW、完整CN GeoSite与MetaDB、Controller空闲、真实Linux TUN，每窗60秒，单源IP且每UDP关联一个目标。这是历史体验基线，不签当前6c3e3c2的高并发或真机结果。

| 场景 | 实际业务连接 | 吞吐 Mbps | CPU % | RSS MiB | UDP丢包 % | 最终状态 |
|---|---|---:|---:|---:|---:|---|
| 单TCP下行 | 1 TCP | 999.974502 | 77.084215 | 20.972656 | N/A | 完整交付，记录单流容量 |
| 日常 | 32 TCP＋32 UDP | 103.999168 | 12.873191 | 22.523438 | 0 | 有限任务完整交付 |
| 少量慢连接混合 | 32 TCP＋32 UDP | 103.998848 | 12.756615 | 22.523438 | 0 | 有限任务完整交付 |
| 高并发 | 256 TCP＋256 UDP | 996.631473 | 196.423387 | 45.500000 | 0 | RSS超过43MiB，FAIL；优化暂缓 |

日常与混合慢读各完成372个任务；混合场景仅4条TCP中段限128KiB/s，约16秒完成，恢复任务P95为970.940ms，正常组中段TCP P95较日常增加约0.09%。这些延迟含人为发送节奏，不是网页首字节；单轮不证明重复统计或设备表现。

前三窗活动DNS均1200/1200，TCP字节及校验完整。高并发512条连接准备成功，准备DNS512查询尝试541次，29次在同一原5秒期限内有限重发后成功；活动DNS发送59992次全部成功，原计划60000次中跳过8次，driver_complete=false保留。实际TCP完整和UDP零丢包不抵消内存FAIL；CPU墙时包括准备重发，不能据此认定转发优化。

历史高并发c66757b为51.78MiB，d96ffe8按需分配版本为46.70MiB，均未达到43MiB。后续45.50MiB变化未证明是新的Core缓冲或allocator优化。准备失败未形成完整负载的窗口不用于内存收益比较。
